# Project Remix 한국어 위키

Roblox 게임 **Project Remix**의 무기·능력·리믹스·특전·상태이상·맵·게임모드·패치 기록을 정리한 비공식 한국어 팬 위키입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 위키 사이트 전체 (데이터와 이미지가 파일 안에 들어 있어 이 파일 하나로 동작) |
| `data.json` | 원문(영어) 기반 구조화 데이터 |
| `data_ko.json` | 한국어로 번역·요약·재구성한 데이터 (`index.html`에 들어간 데이터와 같음) |

## 출처와 라이선스

### 문서 내용 — CC BY-SA 4.0

문서 내용은 [Project Remix Wiki](https://projectremix.miraheze.org/)(Miraheze)의 콘텐츠를 바탕으로 합니다.
원문은 [크리에이티브 커먼즈 저작자표시-동일조건변경허락 4.0 국제 라이선스(CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/)로 제공됩니다.

- **변경 사항:** 원문 위키 내보내기 파일(`Project+Remix+Wiki-20261123042334.xml`)에서 내용을 구조화된 데이터로 추출했고, 한국어로 번역·요약·재구성했습니다. 일부 스탯과 설명은 원문 수정일 이후의 공식 패치노트를 반영해 갱신했습니다.
- 이 저장소의 문서 내용(`index.html`·`data.json`·`data_ko.json`의 글)은 원문과 같은 **CC BY-SA 4.0**으로 배포됩니다.
- 각 문서 하단에 원문 위키 페이지 링크와 원문 수정일이 표시됩니다. 원문 기여자 목록은 각 위키 페이지의 역사(history)에서 확인할 수 있습니다.

### CC BY-SA 4.0 적용 대상이 아닌 것

- **게임 이미지** (아이콘·스크린샷·GIF): 저작권은 각 권리자에게 있습니다.
- **패치 기록** (`updates`, `patchHistory`): Project Remix 공식 Discord 업데이트 공지를 원문 그대로 옮긴 것으로, 저작권은 개발진에게 있습니다.

## 비공식 안내
